# 🛡️ Projecte Web Educatiu – Simulació de Serveis de Ciberseguretat

📌 Descripció del projecte

Aquest projecte consisteix en el desenvolupament d’una pàgina web fictícia creada amb PHP i HTML, amb l’objectiu de simular una plataforma de serveis relacionats amb la ciberseguretat, centrada en la conscienciació sobre atacs DDoS.

La pàgina NO ofereix serveis reals ni promou activitats il·legals.
La seva finalitat és educativa, per practicar:

Desenvolupament web amb PHP i HTML

Disseny d’interfícies

Gestió de formularis

Estructura de projectes web

Conscienciació sobre ciberatacs

🎯 Objectius

Aprendre a estructurar una web amb PHP

Simular una plataforma de serveis ficticis

Entendre què és un atac DDoS i els seus riscos

Practicar el disseny i la navegació web

Desenvolupar un projecte amb un enfocament ètic i educatiu

🛠️ Tecnologies utilitzades

HTML5 – Estructura de la pàgina

CSS3 – Estils (si s’aplica)

PHP – Lògica del servidor

Servidor local (XAMPP / WAMP / Laragon)


⚠️ Avís legal

Aquest projecte és 100% fictici i té finalitats educatives.
No es realitzen atacs reals ni s’ofereixen serveis il·legals.

Qualsevol contingut relacionat amb DDoS és només per a aprenentatge i conscienciació sobre els riscos de la ciberseguretat.
